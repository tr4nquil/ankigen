# AnkiGen

An AI-powered Streamlit app that converts your notes into an Anki package, ready to be imported as a full deck. Paste notes, upload a file, or both and receive a `.apkg` file generated by Google's Gemini API. 

## Features

- Generate flashcards from pasted notes and/or an uploaded text file.
- Set your own study level for variable complexity cards (GCSE/A level/University).
- Adjustable card count.
- Ability to add custom instructions alongside pasted notes.
- MathJax support for mathematical notation.
- Automatic conversion from model JSON output to `.apkg` file.

## Setup

1. Clone the repository and create a virtual environment:
```
git clone https://github.com/tr4nquil/ankigen.git
cd ankigen
python3 -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows
```

2. Install dependencies:
```
pip install -r requirements.txt
```

3. Get a free API key from [Google AI studio](https://aistudio.google.com), then create a `.env` file:
```
GEMINI_API_KEY="<your_api_key>"
```

4. Run the app:
```
streamlit run app.py
```


## Usage

After following setup instructions the application is available to be accessed in the browser, usually at `http://localhost:8501`.

The user is then able to interact with the program to specify:
- Anki deck name (topic/module name),
- Text file upload and/or pasted notes,
- Study level,
- Number of cards.

After clicking the Generate button, an API call is sent to the Gemini AI model and the response will be transformed into an Anki deck ready to be downloaded and imported directly into Anki.


## How it works

### 1. Input
The user provides a topic, study level, target card count, and source notes (and/or instructions) by interacting with the Streamlit browser interface hosted on localhost.

### 2. Generation
The application sends text (notes and/or instructions) with the system prompt (`SYSTEM_PROMPT.md`) to the Gemini AI model via the API to generate atomic flashcards returned as structured JSON based on the provided JSON schema. 

### 3. Deck building
The JSON response is parsed into a dictionary of Front and Back pairs. The Genanki package transforms these pairs into notes and appends them to an Anki deck.

### 4. Delivery
The Anki deck is converted into an Anki-compatible package. The package is then served back to the user via the browser as a downloadable `.apkg` file. This file can be opened directly and imported into Anki as a new deck.

## Design decisions

- `model_id` is kept the same to prevent multiple different note types cluttering Anki. `deck_id` is randomised on the assumption that each set of notes will be its own Anki deck, which prevents all generated decks across different sessions from collapsing into a single deck.
- `application/json` mime type is used to enforce the specific JSON schema required for conversion into Anki cards. MathJax formatting instructions are included separately inside `SYSTEM_PROMPT.md` as they are not always required.
- The Anki package is written to an in-memory buffer instead of disk to allow the user to selectively download only the decks that are required and correct, instead of every created deck.
